# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this project, please report it responsibly by following these steps:

1. Do not disclose the vulnerability publicly
2. Contact the project maintainers directly at [insert email address]
3. Provide detailed information about the vulnerability, including:
   - Description of the issue
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if possible)

We will acknowledge your report and work to fix the issue as quickly as possible.

## Security Best Practices

This project follows several security best practices:

1. **Input Validation**: All user inputs are validated to prevent injection attacks
2. **Error Handling**: Proper error handling is implemented to avoid exposing sensitive information
3. **Data Protection**: User data is stored securely and only used for the intended purpose
4. **API Security**: When using external APIs, proper authentication and authorization are implemented
5. **Code Review**: All code changes are reviewed before being merged to ensure security

## Data Privacy

This extension does not collect or store any personal user data. It only stores user preferences (such as target language and translation service) in the browser's local storage.

## Third-party Dependencies

This project uses third-party libraries and APIs. We regularly review and update dependencies to ensure they are secure and up-to-date.

## Security Updates

We will release security updates as needed to address vulnerabilities. Users are encouraged to keep their extensions updated to the latest version.
